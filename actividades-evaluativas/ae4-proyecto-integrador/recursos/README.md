## Para la opción 2 (Teachable Machine)

- En Teachable Machine, el botón **Exportar modelo** ofrece un **vínculo compartible** (el modelo queda alojado en los servidores de Google) y el código de ejemplo en JavaScript para usarlo en una página web. Cualquiera de las dos formas sirve como demostración mínima.
- Guarda tu proyecto con **Archivo → Guardar proyecto en Drive** para no perder los datos de entrenamiento.
- Para el conjunto de prueba propio, puedes subir imágenes o audios nuevos en la vista previa del modelo y anotar en una tabla la predicción y la confianza de cada uno. Con esa tabla construyes la matriz de confusión.
