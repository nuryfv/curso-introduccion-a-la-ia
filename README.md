## ¿Cómo está organizado el repositorio?

```
introduccion-ia-udes/
├── syllabus/                 → enlace y resumen del syllabus
├── guias/                    → cómo preparar el entorno, usar Git y entregar en Teams
├── semana-01-.../            → una carpeta por semana
│   ├── README.md             → guía de la semana (empieza aquí)
│   ├── capitulo/             → documento tipo capítulo de libro con el contenido
│   ├── complementos/         → videos y herramientas para practicar
│   ├── practicas/            → notebooks y código de la semana
│   └── materiales-adicionales/ → artículos, enlaces y lecturas opcionales
├── actividades-evaluativas/  → enunciados y rúbricas de las 4 entregas (25 % c/u)
└── recursos/                 → bibliografía, datasets y plantillas
```

## Tu ruta cada semana

1. Abre el `README.md` de la carpeta de la semana.
2. Lee el capítulo de la carpeta `capitulo/`.
3. Revisa los videos y herramientas de `complementos/`.
4. Haz la práctica de `practicas/`.
5. Anota tus dudas y llévalas a la sesión sincrónica.
6. En semanas pares, entrega la Actividad Evaluativa en Teams.
